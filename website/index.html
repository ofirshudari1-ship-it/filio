Three steps

From the moment a file lands, to the moment it's filed

No manual filing, no trying to remember what you saved where — it all happens automatically in the background.

1

Watching your downloads

A new file is saved to a folder you're watching. Filio notices immediately and waits for the download to fully finish — including files still syncing from OneDrive or Dropbox.

2

Local recognition, not the cloud

Reads the PDF's content and the file name, and compares them against the rules and clients you've defined. Every decision comes with a plain explanation — which word was found, and where.

3

Filed in the right place

Moves the file into Client → Year → Type, sends a quick notification, and logs everything — with one-click undo if the detection got it wrong.

Product features

Not just "moving files"

Every feature here came from a real problem — either we ran into it ourselves, or a competing tool leaves it unsolved.

📷

Reads photos too, not just PDFs

Local OCR (English + Hebrew) recognizes text inside a photo or scan of an invoice, and classifies it exactly like a PDF — entirely on your own computer.

🗂️

Multiple watch folders at once

Downloads, Desktop, an email-attachments folder — it watches all of them at the same time, not just one.

💓

Self-healing

A health check every 30 seconds recovers on its own from the glitches that make other tools quietly "stop working."

🧭

Explains itself

Every line in the activity log comes with an explanation: which word was matched, in the content or the file name — not a black box.

🧬

Duplicate detection

A file already filed before (by content, not just name) is transparently routed to "possible duplicates" — never silently overwritten.

☁️

Cloud-aware

Recognizes OneDrive/Dropbox/Google Drive folders and waits for a file to finish downloading before touching it.

↩️

Always undoable

Got the detection wrong? One click in the activity log puts the file back exactly where it was. Nothing is ever deleted.

🛡️

Defender check before every filing

Filio doesn't build its own antivirus engine — it asks the Windows Defender already installed and running on your machine. A file flagged as a threat stays exactly where it is and is never filed.

📦

Order for installer files too

You can turn on sorting of exe/msi files into their own folder by year — kept separate from client documents, off by default so it never surprises you.

🧐

Reviews what it isn't sure about, and learns

Optional "ask before filing" mode leaves an unrecognized file for you to confirm instead of guessing. Fix it once in the "Fix / File…" dialog, and Filio can remember the correction for next time.

Security & privacy

Your documents never leave your computer

No account, no API key, no monthly charge — and even the update mechanism is built so it can't be exploited.

🔒

Fully local classification

The rules engine runs only on your computer. No file, and no text extracted from it, is ever sent to an external server — not even to "improve the service."

🛡️

Secure updates

In-place updates require HTTPS only, and verify the SHA-256 signature of the installer before it runs — a file that doesn't match is deleted instead of opened.

🗑️

Never deletes anything

Duplicates are routed to a separate folder, never overwritten. Every filing action can be undone. Your backups stay yours.

🧪

Defender checks every file — not us

Filio doesn't write antivirus logic. It asks the Windows Defender already installed on your machine. A suspicious file stays untouched — the decision stays in your hands.

🔔

Automatic updates

Filio quietly checks the official GitHub release page once per session and only shows a notification if a newer version exists — it never downloads or installs anything without you clicking through.

Changelog

What changed, version by version

Every version answered a real problem caught in actual use — not cosmetic changes. The full list is kept in CHANGELOG.md.

2.8.0

Review-before-filing + OCR fixSeptember 2026

  • Optional "ask before filing when no client is recognized" mode — an unmatched file waits in Activity as "Needs review" instead of landing under "Unknown Client."
  • New "Fix / File…" dialog in the Activity tab — pick the right client/type for a "Needs review" file, or correct one filed in the wrong place. An optional "remember this" toggle teaches Filio the correction for next time.
  • Fixed: an oversized scanned image could stall the shared OCR engine for every other watched folder, not just itself. Files over 15MB now skip OCR and fall back to filename-only classification.
2.7.1

STANDARDS.md compliance sweepSeptember 2026

  • Fixed a double-launch bug that could let two file watchers race on the same Downloads folder.
  • Installer now defaults to English regardless of Windows locale, and builds as Filio-Setup-<version>.exe instead of a generic name.
2.7.0

Installer files + Windows Defender scanSeptember 2026

  • You can now enable filing of installer files (exe/msi) — off by default, and they get their own separate folder, not mixed with client documents.
  • Every file is checked against Windows Defender (on by default) before filing — a file flagged as a threat stays exactly where it is and is never filed.
  • 93 tests in total — including a real check using the antivirus industry's standard test file (EICAR).
2.6.2

Another integrity check passSeptember 2026

  • Critical fix: syncing Windows auto-start could crash the app on machines with a locked-down corporate policy — fixed before it reached end users.
2.6.1

"Start with Windows" didn't always actually workSeptember 2026

  • Caught on a live machine: the setting said "on" but the actual Windows registry entry was empty. Filio now syncs the registry on every launch, and shows the real state in the settings screen.
2.6.0

Text recognition in images (local OCR)September 2026

  • A local OCR engine (English + Hebrew) reads text out of a photo/scan of an invoice (jpg/png) and classifies it exactly like a PDF — no image is ever sent to a server.
  • The default watched-extensions list was carefully expanded: images and PowerPoint — not "file everything."
  • 85 tests in total — including a real OCR test on an image generated at test time, not mocked.
2.5.1

Stability and compatibility fix roundSeptember 2026

  • 10 real bugs found and fixed in a proactive code review — including a timing race that could lose activity-log entries, and a possible freeze when saving settings with several watch folders.
  • Fixed an issue that could crash the entire app when clicking "Export Settings" to a non-writable destination.
2.5.0

Design and UX upgradeSeptember 2026

  • The settings screen is now built from visual "cards" with graphical on/off toggles instead of checkboxes.
  • Advanced settings (extensions, ignore list, folder order) are hidden by default behind a single panel.
2.4.0

Clarity, UX and securityAugust 2026

  • Every line in the activity log explains why the file was classified the way it was.
  • In-place updates now require HTTPS and verify the installer's SHA-256 signature.
